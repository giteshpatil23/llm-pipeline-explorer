How Generative AI Operates Behind the Scenes

An LLM is not a magic crystal ball. It is an advanced mathematical neural network that takes your raw input text, converts it into structured numerical chunks called tokens, calculates statistical probabilities using learned patterns, and predicts the response one token at a time.

What is a Token?

Computers do not understand text, feelings, or meaning; they only calculate numbers. A token is a chunk of text that an LLM turns into a unique integer ID.

  • Words vs Tokens: A token can be as short as one character ("a") or as long as a whole word ("apple"). In English, 1 token is roughly 4 characters or ~0.75 words.
  • Subwords: Complex or rare words get chopped into pieces. For example, "tokenization" is split into "token" and "ization".
  • Why LLMs use tokens: Tokens strike the perfect balance between keeping the vocabulary size manageable while handling typos, rare words, and multiple languages efficiently.
Notice: This interactive visualizer uses a heuristic educational tokenizer designed for demonstration. Real models (like GPT-4, Gemini, or Claude) use byte-pair encoding (BPE) vocabularies of over 32,000 to 100,000 token entries.

Learn More

Key foundational concepts simplified for first-semester computer science students.

1. What is an LLM?

A Large Language Model (LLM) is a deep neural network containing billions of mathematical weights trained on massive amounts of text. By analyzing sentence patterns across the internet, it learns grammatical rules, facts, and logical associations.

Key Concept: Neural weights & statistical patterns

2. What is a Token?

A token is the atomic unit of text comprehension. Processing individual characters requires too many computing steps, while whole words make vocabularies impossibly large. Subword tokenization represents the optimal computational middle ground.

Key Concept: Subword vocabulary matrix mapping

3. Next-Token Prediction

At its core, an LLM generates text through next-token prediction. Given all preceding tokens, it calculates a probability score for every word in its vocabulary, picks the best candidate, appends it to the prompt, and repeats the loop autoregressively.

Key Concept: Autoregressive probability generation
